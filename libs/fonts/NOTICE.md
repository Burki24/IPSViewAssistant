# Bundled preview fonts

The files in this directory are compact WOFF2 derivatives used only inside the self-contained SVG live preview. They contain Latin-1 characters, have neutral internal family names (`IPSViewPreviewFont01` through `IPSViewPreviewFont08`) and are not installed as system fonts.

| Preview selection | Source font | Included weights | License |
|---|---|---:|---|
| Roboto | Roboto | 400, 700 | Apache License 2.0 |
| RobotoMono | Roboto Mono | 400, 700 | Apache License 2.0 |
| DancingScript | Dancing Script | 400, 700 | SIL Open Font License 1.1 |
| IndieFlower | Indie Flower | 400 | SIL Open Font License 1.1 |
| OpenSans | Open Sans | 400, 700 | Apache License 2.0 |
| PTSans | PT Sans | 400, 700 | ParaType Free Font License |
| BebasNeue | Bebas Neue | 400 | SIL Open Font License 1.1 |
| Segment7 | Digital Numbers (seven-segment preview substitute) | 400 | SIL Open Font License 1.1 |
